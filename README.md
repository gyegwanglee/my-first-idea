# 내 첫 번째 아이디어 (My First Idea)

Day 1 - 웹 인터랙티브 프로젝트

## 🚀 프로젝트 소개
- 감각적이고 세련된 딥 블루 & 시안 네온 테마의 글래스모피즘 디자인
- 마우스 인터랙션 기반 3D 카드 틸트(Tilt) 및 마우스 글로우 추적 효과
- 영감 문구 전환 및 화려한 파티클 버스트 애니메이션

## 🛠️ 기술 스택
- **HTML5**
- **CSS3** (Glassmorphism, Ambient Orbs, CSS Custom Properties, Keyframe Animations)
- **Vanilla JavaScript** (DOM API, Interactive Animations)
